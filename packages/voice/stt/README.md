# STT (Expo Speech Recognition)

This package provides the Expo-only speech recognition wrapper for AURA voice input.

## Included

- `ExpoSpeechRecognitionSession` session wrapper
- Normalized STT status, transcript, and error types
- Permission-aware start/stop/cancel flow

## Excluded

- No whisper.cpp bindings
- No PCM chunking pipeline
- No legacy benchmark or smoke harness
